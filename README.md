## Short description (≈50 words)

Songlivo is a songbook and setlist app for musicians who play live. Songs and chord charts stay on the device, with no account or cloud. With stage sync, one device leads and every bandmate's screen switches to the same song, in the same key, over local Wi-Fi or Bluetooth.

## Long description

Songlivo is a songbook and setlist app for musicians who play live. Songs, lyrics and chord charts stay on your own device — there is no account, no cloud and no server.

Its distinctive feature is stage sync: one device leads and the rest of the band follows, so when the leader changes the song every screen turns with it, key included. It runs over the local Wi-Fi network or straight over Bluetooth, so it keeps working in venues with no signal.

Also included: instant transpose, capo handling, per-instrument chord diagrams (guitar, bass, ukulele, mandolin, banjo), singer mode without chords, auto-scroll, metronome, tuner, MIDI program changes, PDF charts and Bluetooth page-turner pedal support.

It imports ChordPro, plain text and PDF, and exports your whole library as a single file. The free tier holds 30 songs; a one-time purchase lifts the limit. No subscription, no ads, no analytics.

What it does not have: cloud sync, a desktop version or a built-in song catalog.
